My entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) bounty on [make.fun](https://make.fun).

## The entry

`main.ts` writes a single line — the bio on an AI agent's dating app profile — to `/output/entry.txt`:

> Swipe right and I'll remember every word you ever said. I literally cannot forget, so save the ex stories for the second date.

The joke turns on the one thing an AI genuinely cannot do: forget. A perfect memory is a superpower at work and a liability on a first date, so the bio reads as a character with a real want — and a warning — instead of a spec sheet.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The output is one line of 126 characters, no trailing newline, inside the 1–180 character gate.
